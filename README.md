# eulst.app

Le laboratoire d'eulst : une vitrine d'outils, d'expériences et de jeux web, servie par Next.js sur Vercel (chaque push sur `main` est mis en production).

- **Pour travailler sur le site (humain ou agent)** : lire [`AGENTS.md`](AGENTS.md), qui décrit l'architecture, les apps, les secrets et les vérifications.
- **Historique détaillé** : [`docs/EULST-HOME.md`](docs/EULST-HOME.md).

```bash
npm ci
npm run dev     # http://localhost:3000
npm run build   # nécessite Internet (polices Google)
```

Le nom du dépôt (`broll-finder`) est historique : B-Roll Finder fut le premier outil hébergé ici.
